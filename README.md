# 🎯 How Much?

**How Much?** is a multiplayer trivia game where players compete to guess quantities, measurements and numerical facts about the world.

How tall is the Eiffel Tower? How many people live in Tokyo? How deep is the ocean?

The goal is to get as close as possible to the correct answer and compete against other players!

## 🌐 Play the Game

**[🚀 Play How Much?](https://howmuchgrup6.dam.inspedralbes.cat/)**

## 🎮 Features

- **Multiplayer:** Create or join game sessions and compete with other players.
- **User Accounts:** Register, log in and create your own player profile.
- **In-Game Chat:** Communicate with other players during game sessions.
- **Statistics:** Track your performance and review your game statistics.
- **Nicknames & Avatars:** Personalize your player profile.
- **Interactive Questions:** Answer questions about measurements, distances, populations and other interesting facts.
- **Host Controls:** Game hosts can manage their sessions and remove players when necessary.

## 🕹️ How to Play

1. Create an account or log in.
2. Create a multiplayer session or join an existing one.
3. Read each question carefully.
4. Enter your estimated numerical answer.
5. Get as close as possible to the correct answer.
6. Compete with other players and check your results!

## 🛠️ Technologies Used

- **JavaScript** – Main programming language.
- **Vue.js** – Frontend framework used to build the user interface.
- **MariaDB** – Relational database used to store application data.
